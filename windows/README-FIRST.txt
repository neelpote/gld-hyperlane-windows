GLD Windows Kit

Read GLD-Windows-Step-by-Step.pdf.
Use existing-route to operate the already deployed route.
Use fresh-route only to create a separate new token and route.
No private key or recovery phrase is included.
Set HYP_KEY locally in .env to an ACCOUNT PRIVATE KEY, never a seed phrase.
Run PowerShell commands with npm.cmd. Hyperlane is launched through Node for Windows compatibility.
Windows execution was not available for testing; the core on-chain flow was tested on macOS.
